## 1. 产品概述

基于 IPFS 的分布式文件分享站，用户可通过拖拽方式上传文件至 IPFS 网络，获取唯一 CID 标识，并在资源库中浏览、预览已上传的图片和 PDF 文件。

- 目标用户：需要去中心化文件存储与分享的开发者及普通用户
- 核心价值：无需中心化服务器，文件永久存储于 IPFS 网络，CID 即链接

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 访客 | 无需注册 | 上传文件、浏览资源库、预览文件 |

### 2.2 功能模块

1. **上传页面**：拖拽上传区域、上传进度条、CID 返回结果展示
2. **资源库页面**：CID 文件列表、文件类型图标、文件大小、上传时间、预览入口

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 上传页面 | 拖拽上传区 | 支持拖拽或点击选择文件，显示文件名和大小 |
| 上传页面 | 进度展示 | 实时展示上传进度百分比，上传完成后显示 CID |
| 上传页面 | CID 结果 | 展示 CID 值，提供一键复制功能 |
| 资源库页面 | 文件列表 | 以卡片/列表形式展示所有上传的文件 CID、文件名、大小、类型 |
| 资源库页面 | 预览功能 | 图片类型直接展示缩略图，PDF 提供 IPFS 网关在线预览链接 |
| 资源库页面 | 筛选排序 | 按文件类型筛选（全部/图片/PDF/其他），按时间排序 |

## 3. 核心流程

用户打开站点 → 进入上传页面 → 拖拽或选择文件 → 文件上传至 IPFS → 返回 CID → 用户复制 CID 或前往资源库 → 在资源库中浏览已上传文件 → 点击预览查看图片或 PDF

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 (#1a1a2e) 搭配霓虹青 (#00d4aa) 作为强调色，营造赛博朋克/去中心化科技感
- 辅助色：暗紫 (#16213e) 用于卡片背景，亮橙 (#ff6b35) 用于进度条
- 按钮风格：圆角微凸起，hover 时发光效果
- 字体：Outfit（标题）+ DM Sans（正文），科技感与可读性兼顾
- 布局风格：顶部导航 + 全屏内容区，卡片式列表
- 图标风格：线性描边图标（lucide-react）

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 上传页面 | 拖拽上传区 | 虚线边框区域，拖入时边框高亮发光，居中上传图标与提示文字 |
| 上传页面 | 进度展示 | 渐变色进度条（青到橙），百分比数字，脉冲动画 |
| 上传页面 | CID 结果 | 代码风格展示 CID，复制按钮带点击反馈 |
| 资源库页面 | 文件卡片 | 暗色卡片，文件类型图标/缩略图，CID 简略展示，悬停发光效果 |
| 资源库页面 | 预览弹窗 | 暗色遮罩层，居中大图/iframe 预览，关闭按钮 |
| 资源库页面 | 筛选栏 | 胶囊式按钮组（全部/图片/PDF/其他），选中状态发光 |

### 4.3 响应式设计

- 桌面优先设计，卡片网格自适应列数
- 移动端单列布局，上传区全宽
- 触摸优化：拖拽区域增大点击热区
