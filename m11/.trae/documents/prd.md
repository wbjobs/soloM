## 1. 产品概述

Raft 共识算法可视化调试平台，通过 3D 可视化方式实时展示 Raft 协议的选举、心跳和日志复制过程，帮助开发者和学生直观理解分布式共识机制。
- 目标用户：分布式系统学习者、后端工程师、技术面试准备者
- 核心价值：将抽象的 Raft 协议过程转化为可交互的 3D 视觉体验，支持故障注入和实时调试

## 2. 核心功能

### 2.1 功能模块

1. **3D 可视化主页面**：3D 服务器节点模型、角色颜色标识、RPC 通信动画、日志流展示
2. **控制面板**：网络分区控制、节点启停、选举触发、日志提交模拟

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 3D 可视化主页面 | 3D 节点场景 | 渲染 3 个 Raft 节点为 3D 服务器模型，根据角色动态变色（Leader 金色、Follower 蓝色、Candidate 橙色） |
| 3D 可视化主页面 | 通信动画 | 节点间动态连线与粒子流，展示心跳、投票请求、日志复制的 RPC 流向 |
| 3D 可视化主页面 | 状态信息浮层 | 悬停节点显示 Term、日志索引、投票信息等详细状态 |
| 控制面板 | 网络分区 | 点击节点切断/恢复网络连接，触发重新选举 |
| 控制面板 | 节点控制 | 启动/停止/重启单个节点 |
| 控制面板 | 日志操作 | 提交新日志条目，观察日志复制过程 |
| 控制面板 | 事件日志 | 实时滚动显示所有 Raft 事件（选举、心跳、日志提交等） |

## 3. 核心流程

**选举流程**：Follower 超时 → 转为 Candidate → 发起投票请求 → 获得多数票 → 成为 Leader → 开始发送心跳

**日志复制流程**：客户端请求 → Leader 追加日志 → 广播 AppendEntries → Follower 确认 → Leader 提交 → 通知客户端

**网络分区流程**：用户切断节点网络 → 节点停止收发 RPC → 剩余节点重新选举 → 恢复网络 → 节点重新加入集群并同步日志

```mermaid

    "Follower 超时" --> "转为 Candidate"
    "转为 Candidate" --> "增加 Term，投自己一票"
    "增加 Term，投自己一票" --> "广播 RequestVote RPC"
    "广播 RequestVote RPC" --> "收到多数票?"
    "收到多数票?" -->|"是"| "成为 Leader"
    "收到多数票?" -->|"否"| "收到更高 Term?"
    "收到更高 Term?" -->|"是"| "回退为 Follower"
    "收到更高 Term?" -->|"否"| "选举超时，重试"
    "成为 Leader" --> "发送心跳 AppendEntries"
    "发送心跳 AppendEntries" --> "维持 Leader 地位"
    "维持 Leader 地位" --> "客户端请求"
    "客户端请求" --> "Leader 追加日志"
    "Leader 追加日志" --> "广播 AppendEntries"
    "广播 AppendEntries" --> "多数确认后提交"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深色科技风背景（#0a0e1a），搭配青色（#00f0ff）作为科技感强调色
- 辅助色：金色（#ffd700）用于 Leader 标识，蓝色（#4a9eff）用于 Follower，橙色（#ff8c00）用于 Candidate
- 按钮风格：圆角半透明玻璃态按钮，悬停时发光
- 字体：Orbitron（标题/数据），JetBrains Mono（代码/日志）
- 布局：左侧 3D 场景占据主要空间，右侧控制面板，底部事件日志

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 3D 可视化主页面 | 3D 节点场景 | 深色背景、3D 服务器模型、节点名称标签、角色色光环、粒子流连线 |
| 3D 可视化主页面 | 状态浮层 | 半透明毛玻璃卡片、Term/LogIndex/VoteFor 信息、角色标识徽章 |
| 控制面板 | 网络控制 | 节点网格（3个节点卡片）、开关按钮（网络连通/断开）、状态指示灯 |
| 控制面板 | 操作按钮 | 提交日志按钮、触发选举按钮、重置集群按钮 |
| 控制面板 | 事件日志 | 深色终端风格滚动区域、时间戳+事件类型+详情、语法高亮 |

### 4.3 响应式设计

- 桌面优先设计，3D 场景在大屏获得最佳体验
- 平板适配：控制面板折叠为底部抽屉
- 移动端：简化 3D 渲染，控制面板全屏覆盖

### 4.4 3D 场景指引

- 环境：深色星空背景，微弱网格地面，营造科幻监控室氛围
- 灯光：柔和环境光 + 节点自带点光源（颜色随角色变化）
- 相机：默认 45 度俯瞰，支持 OrbitControls 自由旋转缩放
- 构图：3 个节点呈三角形排列，Leader 居上方
- 交互：点击节点选中、滚轮缩放、拖拽旋转
- 后期处理：Bloom 发光效果增强节点光晕和粒子流
- 性能预算：60fps，粒子数上限 2000
