## 1. 产品概述

天体物理 N-Body 引力模拟与可视化系统，面向天文爱好者、物理研究者和教学场景，提供实时大规模星体引力相互作用模拟及沉浸式 3D 可视化体验。

- 核心功能：基于 Barnes-Hut 算法的高效 N 体引力计算 + WebGL 实时粒子渲染
- 目标用户：天体物理研究者、物理教师、学生、科学可视化爱好者
- 产品价值：将复杂的物理计算过程可视化，让抽象的引力相互作用变得直观可感知

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 浏览模拟、调整参数、控制模拟流程 |

### 2.2 功能模块
1. **3D 可视化主界面**：WebGL 粒子系统渲染、星体运动轨迹、相机交互控制
2. **模拟控制面板**：参数调节（引力常数、时间步长、星体数量）、模拟控制（开始/暂停/重置）
3. **实时数据流**：WebSocket 实时推送星体坐标数据、性能指标显示
4. **预设场景**：星系碰撞、星团演化、三体问题等经典天体物理场景

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 3D 场景模块 | Three.js 渲染星体粒子、运动轨迹拖尾、星空背景 |
| 主页面 | 控制面板模块 | 侧边折叠面板，包含模拟参数滑块、控制按钮、预设场景选择 |
| 主页面 | 状态显示模块 | 实时 FPS、星体数量、计算耗时等性能指标 |

## 3. 核心流程

用户访问页面 → 自动连接后端 WebSocket 服务 → 选择预设场景或自定义参数 → 点击开始模拟 → 后端进行 Barnes-Hut 引力计算 → 实时推送星体坐标数据 → 前端 WebGL 渲染粒子运动 → 用户可随时暂停/重置/调整参数

```mermaid
    H --> E
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深空蓝 (#0a0e1a) 为背景，配合冷白 (#e6f1ff) 文字，星体粒子使用蓝紫渐变色系
- **辅色调**：星云紫 (#6366f1)、星际青 (#22d3ee)、恒星黄 (#fbbf24) 用于粒子分类和高亮
- **按钮风格**：玻璃拟态风格，半透明背景 + 模糊效果，圆角 8px，悬停时有辉光效果
- **字体**：标题使用 Orbitron（科技感无衬线字体），正文使用 JetBrains Mono（等宽字体增强数据感）
- **布局风格**：沉浸式全屏 3D 场景，右侧悬浮半透明控制面板，左上角状态显示
- **视觉元素**：噪点纹理背景、扫描线效果、发光边框、数据可视化 HUD 元素

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 主页面 | 3D 场景模块 | 全屏 Canvas、星空背景、发光粒子、运动拖尾、轨道线、相机阻尼旋转 |
| 主页面 | 控制面板模块 | 折叠侧边栏、滑块控件、分段控制器、发光按钮、场景选择卡片 |
| 主页面 | 状态显示模块 | HUD 风格数据面板、实时 FPS 图表、连接状态指示 |

### 4.3 响应性
- 桌面端优先设计，全屏 3D 场景 + 右侧固定控制面板（320px 宽度）
- 平板端：控制面板宽度自适应，支持手势旋转场景
- 移动端：控制面板改为底部抽屉式，简化控制选项

### 4.4 3D 场景指引
- **环境与氛围**：深空场景，程序化生成星空背景，远处星云体积光效果
- **光照设置**：无主光源，星体自发光材质，根据质量/速度调整亮度和颜色
- **相机设置**：PerspectiveCamera，初始位置距离场景中心 100 单位，支持 OrbitControls 自由旋转缩放
- **构图与焦点**：星体群位于场景中心，相机自动跟踪密度最高区域
- **交互与动画**：星体运动平滑插值，轨迹拖尾使用 BufferGeometry 动态更新，参数变化时有过渡动画
- **后处理效果**：Bloom 泛光效果增强星体发光感，轻微色差提升科幻感
- **性能预算**：粒子数量上限 10000，轨迹点保留 200 帧，目标帧率 60fps
