# 分子动力学 3D 交互可视化

一个基于 Three.js 前端和 Python 后端的蛋白质结构可视化项目。

## 功能特性

- 🧬 **PDB 文件解析**: Python 后端解析标准 .pdb 格式的蛋白质结构文件
- 🎨 **高效渲染**: 使用 Three.js 的 InstancedMesh 技术高效渲染成千上万个原子球体
- 🖱️ **交互控制**: 
  - 左键拖拽：旋转分子结构
  - 右键拖拽：平移分子结构
  - 滚轮：缩放视图
- 🌈 **元素着色**: 不同元素使用不同颜色和大小渲染
- ✨ **视觉效果**: 星空背景、光照效果、阴影渲染

## 项目结构

```
.
├── backend.py          # Python Flask 后端服务
├── index.html          # 前端 3D 可视化页面
├── structure.pdb       # 示例蛋白质结构文件
├── requirements.txt    # Python 依赖
└── README.md           # 项目说明
```

## 安装与运行

### 1. 安装 Python 依赖

```bash
pip install -r requirements.txt
```

### 2. 启动后端服务

```bash
python backend.py
```

### 3. 访问可视化页面

打开浏览器访问: `http://localhost:5000`

## 使用说明

### 替换自己的 PDB 文件

将你的 `.pdb` 文件重命名为 `structure.pdb` 并替换项目中的同名文件即可。

### 支持的元素

项目内置了以下元素的颜色和大小配置：

| 元素 | 颜色 | 相对大小 |
|------|------|----------|
| C (碳) | 青色 | 0.7 |
| O (氧) | 红色 | 0.6 |
| N (氮) | 蓝色 | 0.65 |
| S (硫) | 黄色 | 1.0 |
| H (氢) | 白色 | 0.4 |
| P (磷) | 橙色 | 0.9 |
| 其他金属元素 | - | - |

## 技术实现

### 后端 (Python)

- 使用 Flask 框架提供 REST API
- 解析 PDB 文件格式，提取原子坐标和元素信息
- 支持 CORS 跨域访问

### 前端 (Three.js)

- **InstancedMesh**: 通过单个几何体和材质实例化多个网格，大幅提升渲染性能
- **Phong 材质**: 实现金属光泽效果
- **阴影映射**: 增强 3D 空间感
- **惯性旋转**: 松手后继续旋转并逐渐减速，提供流畅的交互体验

## 性能优化

- 使用 InstancedMesh 代替多个独立 Mesh，减少 draw call
- 按元素分组创建多个 InstancedMesh，支持不同颜色和大小
- 合理的几何体细分（32x32 球体）平衡画质与性能
