## 1. 产品概述

本地优先（Local-First）的加密协作文档编辑器，支持离线编辑的 Markdown 协作编辑平台。前端使用 React + Yjs（CRDT）实现无冲突的本地状态管理，底层存储使用 IndexedDB 实现数据持久化；后端使用 WebSocket（Socket.io）仅做二进制更新广播，不存任何业务数据。所有文档内容在传输前通过 Web Crypto API 进行端到端加密，确保服务器无法读取用户数据。

- **核心价值**：数据主权归用户、离线可用、多人实时协作、端到端加密保护隐私
- **目标用户**：注重隐私的团队协作者、技术写作者、需要离线工作场景的远程工作者

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 协作者 | 输入昵称加入房间 | 查看、编辑文档，管理加密密钥 |
| 观察者 | 输入昵称加入房间（只读模式） | 仅查看文档内容 |

### 2.2 功能模块

1. **编辑器页面**：Markdown 编辑区域、实时预览、协作光标显示、在线用户列表、连接状态指示

3. **房间页面**：创建/加入协作房间、房间成员显示、房间链接分享

## 3. 核心流程

### 3.1 文档协作编辑流程

用户打开编辑器 → 本地 IndexedDB 加载文档 → 建立 WebSocket 连接 → 与房间内其他用户同步 Yjs 更新 → 所有更新经过加密后传输 → 离线时本地继续编辑 → 重新上线后自动合并 CRDT 更新

### 3.2 端到端加密流程

用户创建文档 → Web Crypto API 生成 AES-GCM 密钥 → 密钥通过 PBKDF2 从用户密码派生 → 文档内容加密后写入 IndexedDB → 网络传输仅发送密文 → 其他协作者使用相同密钥解密

    "解密文档内容（E2EE）" --> "初始化 Yjs 文档"

    "连接 WebSocket 服务器" --> "加入协作房间"

    "接收远端更新（密文）" --> "解密远端更新"

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色主题 — 深灰/墨黑底色（#0D1117, #161B22），翡翠绿强调色（#00D68F），琥珀色警告色（#FFB800）
- **次要色调**：冷灰中性色系（#8B949E, #30363D），加密相关使用紫色点缀（#A371F7）
- **按钮风格**：圆角（8px），轻微投影，翡翠绿主按钮，灰色次按钮，危险操作红色
- **字体**：编辑器使用等宽字体 JetBrains Mono，UI 使用 DM Sans
- **布局风格**：侧边栏导航 + 主编辑区域，顶部工具栏，可折叠面板
- **图标**：使用 Lucide 图标库，线性风格，与深色主题统一

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 编辑器页面 | Markdown 编辑器 | 深色代码编辑区域，行号，语法高亮，等宽字体，最小高度100vh |
| 编辑器页面 | 实时预览面板 | 右侧分栏，Markdown 渲染样式，与编辑器等高同步滚动 |
| 编辑器页面 | 协作光标 | 彩色光标标签（显示用户名），半透明选中高亮 |
| 编辑器页面 | 在线用户列表 | 右侧可折叠面板，用户头像色块+名称+在线状态指示灯 |
| 编辑器页面 | 连接状态指示 | 底部状态栏绿色/黄色/红色圆点 + 文字状态 |
| 编辑器页面 | 离线指示器 | 顶部琥珀色横幅，"离线编辑中 — 恢复连接后自动同步" 文字 |
| 文档管理页面 | 文档列表 | 卡片式布局，每张卡片显示文档标题、修改时间、加密锁图标 |
| 文档管理页面 | 新建文档 | 居中模态框，输入标题、设置加密密码 |
| 文档管理页面 | 密钥管理 | 模态框，显示密钥指纹，导出/导入按钮 |
| 房间页面 | 创建房间 | 居中表单，房间名称输入，创建按钮，生成分享链接 |
| 房间页面 | 加入房间 | 输入房间 ID 或链接，输入加密密码，加入按钮 |

### 4.3 响应式设计

- 桌面优先设计，1280px 以上完整双栏编辑器+预览
- 1024px-1280px 编辑器与预览上下排列
- 768px 以下仅显示编辑器，预览通过标签页切换
- 触摸设备支持手势滑动切换编辑/预览模式

### 4.4 设计灵感

- **氛围**：开发者工具质感 — 类似 VS Code / Obsidian 的深色专业编辑环境
- **动效**：连接状态切换时的微动画，光标出现/消失的渐变过渡，离线横幅的滑入动画
- **特色**：加密盾牌图标动态呼吸效果，表示文档处于加密保护中
