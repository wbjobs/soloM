## 1. 产品概述

局域网文件快传是一款无需登录、即开即用的 P2P 文件传输工具。基于 WebRTC 技术实现浏览器端到端直连，文件数据不经过服务器，信令服务器仅用于协助双方交换连接信息。
- 解决局域网内设备间快速传文件的痛点，无需安装软件、无需注册账号
- 目标用户：同一局域网内需要在手机、电脑等设备间互传文件的普通用户

## 2. 核心功能

### 2.1 用户角色
无需角色区分，所有用户均为对等节点。

### 2.2 功能模块
1. **房间页面**：创建/加入房间，建立 P2P 连接
2. **传输页面**：拖拽发送文件、接收文件、传输进度展示

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 房间页面 | 房间操作区 | 显示当前房间ID，一键复制；输入房间ID加入对方房间 |
| 房间页面 | 连接状态指示 | 显示 WebRTC 连接状态（等待中/已连接/断开） |
| 传输页面 | 拖拽上传区 | 拖拽或点击选择文件，支持多文件同时发送 |
| 传输页面 | 发送进度条 | 显示每个文件传输进度百分比和速度 |
| 传输页面 | 接收列表 | 显示已接收文件，点击下载保存 |

## 3. 核心流程

用户 A 打开网页获得房间 ID → 用户 B 输入房间 ID 加入 → 信令服务器协助交换 SDP 和 ICE → WebRTC P2P 连接建立 → 拖拽文件发送 → 对方接收并下载

```mermaid
flowchart TD
    "A打开网页" --> "A获取房间ID"
    "B打开网页" --> "B输入A的房间ID"
    "A获取房间ID" --> "A创建RTCPeerConnection"
    "B输入A的房间ID" --> "B创建RTCPeerConnection"
    "A创建RTCPeerConnection" --> "A创建Offer SDP"
    "A创建Offer SDP" --> "通过Socket.io发送Offer给B"
    "通过Socket.io发送Offer给B" --> "B收到Offer并创建Answer SDP"
    "B收到Offer并创建Answer SDP" --> "通过Socket.io发送Answer给A"
    "通过Socket.io发送Answer给A" --> "双方交换ICE Candidate"
    "双方交换ICE Candidate" --> "P2P连接建立"
    "P2P连接建立" --> "A拖拽文件发送"
    "A拖拽文件发送" --> "B接收文件并显示进度"
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深空蓝 (#0f172a) + 荧光青 (#22d3ee) 强调色，传达科技感与速度感
- 次要色：暗灰 (#1e293b) 背景层级，白色文字
- 按钮风格：圆角胶囊按钮，hover 时发光效果
- 字体：Outfit（标题） + DM Sans（正文）
- 布局风格：居中卡片式布局，沉浸式全屏暗色背景
- 图标风格：线性 lucide 图标，荧光青色
- 动效：粒子连线背景动画模拟网络连接，拖拽区脉冲呼吸动画

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 房间页面 | 房间操作区 | 卡片容器，房间ID大字展示，复制按钮带动画反馈，加入房间输入框+按钮 |
| 房间页面 | 连接状态 | 圆形状态灯（等待=黄/连接=蓝闪烁/已连接=绿），状态文字 |
| 传输页面 | 拖拽上传区 | 虚线边框大区域，拖入时边框高亮+背景变化，支持点击选择文件 |
| 传输页面 | 进度条 | 细长胶囊进度条，荧光青填充，百分比文字，文件名+大小信息 |
| 传输页面 | 接收列表 | 文件卡片列表，文件图标+名称+大小+下载按钮 |

### 4.3 响应式设计
- 桌面优先设计，支持平板和手机访问
- 拖拽区域在移动端适配为点击上传
- 卡片布局自适应宽度
