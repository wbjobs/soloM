## 1. 产品概述

基于 WebGPU 计算着色器的实时 2D 流体烟雾模拟器，利用 GPU 并行计算能力求解 Navier-Stokes 方程，实现逼真的流体动力学效果。
- 主要目的：展示 WebGPU 计算着色器的强大性能，提供可视化的物理模拟演示
- 目标用户：Web 开发者、图形学爱好者、教育工作者
- 产品价值：作为 WebGPU 技术演示和物理模拟教学工具

## 2. 核心功能

### 2.1 功能模块

1. **模拟主界面**：全屏流体画布、控制面板、交互提示
2. **计算着色器系统**：Navier-Stokes 方程求解（平流、扩散、投影）
3. **渲染系统**：密度场纹理映射、烟雾效果渲染
4. **交互系统**：鼠标拖拽外力注入、速度和染料注入

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 主页面 | 流体画布 | 全屏 WebGPU Canvas，实时渲染流体烟雾效果 |
| 主页面 | 控制面板 | 显示 FPS、分辨率、模拟参数调节按钮 |
| 主页面 | 交互提示 | 鼠标拖拽产生流体效果的操作说明 |

## 3. 核心流程

用户打开页面后，自动初始化 WebGPU 环境并启动流体模拟。用户通过鼠标拖拽与流体交互，系统实时计算并渲染流体运动效果。

```mermaid
flowchart LR
    A["页面加载"] --> B["WebGPU 初始化"]
    B --> C["创建计算管线"]
    C --> D["创建渲染管线"]
    D --> E["启动模拟循环"]
    E --> F["平流计算"]
    F --> G["扩散计算"]
    G --> H["投影计算"]
    H --> I["密度场渲染"]
    I --> J["检测鼠标输入"]
    J --> K["注入外力/染料"]
    J --> E
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深色背景（#0a0a0f），强调科技感
- **强调色**：流体采用渐变色（青色到紫色），营造迷幻烟雾效果
- **字体**：使用现代无衬线字体，简洁科技风格
- **布局**：全屏沉浸式画布，控制面板悬浮于角落
- **视觉效果**：流体自带辉光效果，增强视觉冲击力

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 主页面 | 流体画布 | 全屏 Canvas、流体渐变着色、动态辉光 |
| 主页面 | 控制面板 | 半透明背景、圆角设计、FPS 计数器、重置按钮 |
| 主页面 | 交互提示 | 底部悬浮文字、淡入淡出动画 |

### 4.3 响应性
- 桌面端优先，Canvas 自适应窗口大小
- 支持触摸设备交互（移动端兼容）
- 控制面板在小屏幕上自动调整位置

### 4.4 视觉特效指导
- **流体渲染**：使用双线性过滤，密度场映射为彩色烟雾
- **动态效果**：流体自带微弱的自发光和模糊效果
- **交互反馈**：鼠标位置产生视觉高亮
- **性能优化**：根据设备性能自动调整模拟分辨率
