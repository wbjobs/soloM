## 1. 产品概述

复古风格 RPG 游戏引擎与地图编辑器（Web 版）—— 基于 HTML5 Canvas 的 2D 瓦片地图创作与运行平台，让创作者在浏览器中即可绘制像素风地图、配置事件逻辑，并一键切换到游戏运行模式进行实时体验。
- 面向独立游戏开发者、RPG 爱好者和像素艺术创作者，提供零门槛的地图编辑与即时试玩能力
- 通过在线协作与版本管理，降低多人地图迭代成本，构建轻量级 RPG 创作生态

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 创作者 | 邮箱注册 | 创建/编辑/删除自己的地图，试玩游戏，查看版本历史 |
| 访客 | 无需注册 | 浏览公开地图列表，试玩公开地图 |

### 2.2 功能模块

1. **地图编辑器页**：瓦片绘制工具栏、画布区、图层管理面板、事件对象面板、属性检查器
2. **游戏运行页**：游戏画布、HUD 状态栏、虚拟方向键（移动端）
3. **地图管理页**：地图列表、搜索过滤、版本历史对比、导入/导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 地图编辑器页 | 工具栏 | 画笔/橡皮/填充/选择/事件放置工具，瓦片尺寸切换（16/32px），撤销/重做 |

| 地图编辑器页 | 事件对象面板 | 拖拽放置事件（传送点/NPC/宝箱/触发区域），配置事件属性 |

| 地图管理页 | 导入/导出 | JSON 格式导入/导出地图数据，支持离线编辑 |

## 3. 核心流程

用户打开应用后进入地图管理页，可新建或打开已有地图进入编辑器。在编辑器中使用工具栏绘制地形瓦片，通过图层管理器切换碰撞层设置可通行区域，拖拽事件对象配置交互逻辑。编辑完成后一键切换至运行模式，角色出现在地图出生点，使用键盘/触控移动角色，碰撞层阻止不可通行区域穿越，事件触发对应交互（传送/对话/拾取）。满意后保存地图，系统自动创建版本快照。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色底 #1a1a2e 搭配暖金色 #e6c068 强调色，辅以暗红 #c0392b（危险操作）和翡翠绿 #27ae60（可通行指示）
- **按钮风格**：像素风圆角按钮，3px 实色边框，按下时内凹 1px 位移模拟物理反馈
- **字体**：标题使用 "Press Start 2P"（Google Fonts 像素风字体），正文使用 "Noto Sans SC"
- **布局风格**：左侧工具栏 + 中央画布 + 右侧属性面板的经典编辑器三栏布局
- **图标风格**：16×16 像素风图标，单色描边，搭配短文字标签
- **整体氛围**：致敬 8-bit/16-bit 时代的 CRT 显示器效果，画布区域可叠加扫描线滤镜

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 地图编辑器页 | 工具栏 | 垂直图标按钮列，当前工具高亮金色边框，tooltip 显示快捷键 |
| 地图编辑器页 | 画布区 | 深色棋盘格背景，半透明网格线，缩放百分比角标，迷你地图右下角 |
| 地图编辑器页 | 图层面板 | 可折叠列表行，眼睛图标显隐，锁图标锁定，拖拽排序手柄 |
| 地图编辑器页 | 瓦片调色板 | 网格排列瓦片缩略图，选中瓦片金色边框，分类 Tab 切换 |
| 地图编辑器页 | 事件对象面板 | 图标+文字列表，拖拽手柄，放置后画布显示菱形标记 |

| 游戏运行页 | HUD 状态栏 | 半透明黑底条，像素字体文字，左下角显示 |
| 游戏运行页 | 虚拟方向键 | 圆形半透明底板，四方向箭头按钮，右下角固定 |

### 4.3 响应式

- 桌面优先设计，最小支持 1024px 宽度
- 编辑器三栏布局在 1024-1440px 下侧面板可折叠
- 1440px 以上全部展开，画布区自适应填充
- 移动端仅支持游戏运行页（虚拟方向键），编辑器需桌面浏览器

### 4.4 CRT 滤镜效果（可选）

- 画布区域可叠加扫描线效果（CSS repeating-linear-gradient）
- 轻微色差偏移模拟（text-shadow 多色叠加）
- 弧形边缘暗角（CSS box-shadow inset）
