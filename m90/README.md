# 分布式服务器集群 CLI 运维审计工具

一个功能强大的分布式服务器集群运维审计工具，支持通过 YAML 配置管理多台服务器，并发执行 Shell 命令，表格化展示结果，并自动记录操作审计日志。

## 功能特性

- ✅ **YAML 配置管理**: 简单易读的服务器配置格式
- 🔐 **多认证方式**: 支持密码认证和 SSH 私钥认证
- ⚡ **并发执行**: 可配置并发数，高效管理多台服务器
- 📊 **表格输出**: 美观的终端表格展示执行结果
- 📝 **审计日志**: 自动记录所有操作到本地 SQLite 数据库
- 🔍 **日志查询**: 支持搜索和查看历史操作记录
- 🎨 **彩色输出**: 友好的命令行交互体验

## 安装

```bash
npm install
```

全局安装（可选）:

```bash
npm link
```

## 快速开始

### 1. 初始化配置

```bash
node src/index.js init
```

这将在 `~/.cluster-audit/servers.yaml` 创建示例配置文件。

### 2. 配置服务器

编辑 `~/.cluster-audit/servers.yaml`:

```yaml
servers:
  - name: web-server-01
    host: 192.168.1.101
    port: 22
    username: root
    password: your_password

  - name: app-server-01
    host: 192.168.1.102
    username: deploy
    privateKey: ~/.ssh/id_rsa
```

### 3. 查看服务器列表

```bash
node src/index.js list
```

### 4. 测试服务器连接

```bash
node src/index.js test
```

### 5. 执行命令

在所有服务器上执行命令:

```bash
node src/index.js exec "uptime"
```

在指定服务器上执行命令:

```bash
node src/index.js exec "df -h" -s web-server-01,app-server-01
```

查看详细输出:

```bash
node src/index.js exec "ls -la" -v
```

设置并发数:

```bash
node src/index.js exec "apt update" -n 10
```

## 命令说明

| 命令 | 说明 |
|------|------|
| `init` | 初始化配置目录并创建示例配置文件 |
| `list` | 列出已配置的所有服务器 |
| `test` | 测试所有服务器的 SSH 连接 |
| `exec <command>` | 在服务器上执行命令 |
| `logs` | 查看审计日志 |
| `logs-clear` | 清空审计日志 |

### exec 命令选项

- `-s, --servers <names>`: 指定服务器名称，多个用逗号分隔
- `-n, --concurrency <number>`: 并发数（默认: 5）
- `-v, --verbose`: 显示详细输出
- `--no-log`: 不记录操作日志

### logs 命令选项

- `-l, --limit <number>`: 显示的日志数量（默认: 20）
- `-s, --search <keyword>`: 搜索关键词
- `-d, --detail <id>`: 查看指定 ID 的日志详情

### logs-clear 命令选项

- `-d, --days <number>`: 只清空指定天数之前的日志
- `-y, --yes`: 确认操作，跳过提示

## 配置文件说明

配置文件采用 YAML 格式，支持以下字段:

| 字段 | 必填 | 说明 |
|------|------|------|
| `name` | 是 | 服务器别名 |
| `host` | 是 | 服务器 IP 或域名 |
| `port` | 否 | SSH 端口（默认: 22） |
| `username` | 是 | SSH 用户名 |
| `password` | 否 | SSH 密码（与 privateKey 二选一） |
| `privateKey` | 否 | 私钥路径或私钥内容（与 password 二选一） |
| `passphrase` | 否 | 私钥密码 |
| `timeout` | 否 | 连接超时（毫秒，默认: 10000） |
| `cwd` | 否 | 命令执行的工作目录 |

## 审计日志

所有操作默认记录到 `~/.cluster-audit/audit.db` SQLite 数据库中，包含以下信息:

- 执行的命令
- 目标服务器
- 执行结果（成功/失败）
- 执行时间
- 执行人
- 并发数
- 详细输出结果
