## 1. 产品概述

分子动力学模拟可视化分析平台是一个面向科研人员与化学/生物信息学学生的 Web 应用，支持用户上传 PDB 分子结构文件，执行能量最小化模拟，并以 3D 交互方式和数据图表直观呈现分子结构与势能变化过程。

- 解决传统分子动力学软件安装复杂、可视化门槛高的问题，提供开箱即用的在线分析体验
- 目标用户：计算化学研究者、结构生物学学生、药物设计从业者

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 上传 PDB 文件、运行模拟、查看 3D 结构与图表 |
| 管理员 | 系统预设 | 管理模拟任务队列、查看系统状态 |

### 2.2 功能模块

1. **模拟工作台页面**：PDB 文件上传、模拟参数配置、启动模拟、3D 分子结构可视化、势能曲线图、模拟状态监控
2. **结果分析页面**：模拟结果回放、能量数据导出、轨迹动画播放

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 模拟工作台 | 文件上传区 | 拖拽或点击上传 PDB 文件，显示文件名与原子数量等基本信息 |
| 模拟工作台 | 模拟参数面板 | 设置力场类型、能量最小化步数、温度等参数，一键启动模拟 |
| 模拟工作台 | 3D 分子查看器 | 使用 NGL.js 加载并渲染分子结构，支持旋转、缩放、平移交互，模拟过程中实时更新构象 |
| 模拟工作台 | 势能曲线图 | 使用 ECharts 绘制模拟过程中势能随步数变化的折线图，实时追加数据点 |
| 模拟工作台 | 模拟状态栏 | 显示当前模拟进度、步骤编号、当前势能值、运行时间 |
| 结果分析 | 轨迹回放 | 加载生成的轨迹文件，逐帧播放分子构象变化动画 |
| 结果分析 | 能量数据面板 | 展示完整的势能变化数据表，支持 CSV 导出 |

## 3. 核心流程

用户打开平台 → 上传 PDB 文件 → 系统解析文件并预览分子结构 → 用户配置模拟参数 → 点击"开始模拟" → 后端调用 OpenMM 执行能量最小化 → 前端轮询/SSE 接收模拟进度与能量数据 → 3D 视图实时更新分子构象 → 势能曲线图同步更新 → 模拟完成 → 用户可回放轨迹或导出数据

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色科技感主题，背景 `#0a0e17`，面板背景 `#111827`，边框 `#1e293b`
- **强调色**：青色 `#06b6d4`（分子高亮、按钮激活）、翠绿 `#10b981`（势能曲线、成功状态）
- **按钮风格**：圆角微透明按钮，悬停时边框发光，主要操作按钮使用青色渐变
- **字体**：标题使用 `JetBrains Mono`（等宽科技感），正文使用 `Inter` 变体或 `IBM Plex Sans`
- **布局风格**：左右分栏布局，左侧 3D 可视化占主区域，右侧控制面板与图表
- **图标风格**：线性图标（Lucide），搭配青色强调

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 模拟工作台 | 文件上传区 | 虚线拖拽区域，中心上传图标，文件信息卡片 |
| 模拟工作台 | 模拟参数面板 | 下拉选择框（力场）、数字输入框（步数/温度）、滑块、启动按钮 |
| 模拟工作台 | 3D 分子查看器 | 全高 Canvas 区域，深色背景，分子球棍模型，底部工具栏（重置视角/切换表示方式） |
| 模拟工作台 | 势能曲线图 | ECharts 折线图，深色主题，青色曲线，网格线半透明 |
| 模拟工作台 | 模拟状态栏 | 进度条、步骤计数器、势能值显示、运行时间 |
| 结果分析 | 轨迹回放 | 播放/暂停按钮、帧进度条、帧号显示 |
| 结果分析 | 能量数据面板 | 数据表格、CSV 导出按钮 |

### 4.3 响应式设计

- 桌面优先设计，主目标分辨率为 1920×1080
- 中等屏幕（1024px-1366px）：控制面板折叠为可展开侧边栏
- 移动端：上下堆叠布局，3D 视图全宽，控制面板下方展示

### 4.4 3D 场景指导

- **环境**：深色背景，无 HDRI，纯黑环境烘托分子发光效果
- **光照**：环境光柔和 + 定向光从左上方照射，分子表面产生高光
- **摄像机**：透视相机，自动居中分子，初始距离适配分子尺寸
- **交互**：鼠标左键旋转、右键平移、滚轮缩放，支持触控手势
- **渲染**：球棍模型（Ball-and-Stick）为默认表示，可切换为卡通模式（蛋白质）、表面模式
